# CSWA & CSWP Study Projects

A collection of my SolidWorks projects and practice exercises as I work toward
the **Certified SOLIDWORKS Associate (CSWA)** and **Certified SOLIDWORKS
Professional (CSWP)** certifications.

## About

This repository documents my progress through hands-on modeling practice. Each
project is an opportunity to improve my understanding of sketching, part
design, and the workflows needed for the CSWA and CSWP exams.

## Projects

Current practice files include:

- Sketch Practice #1
- Sketch Practice #2
- Sketch Practice #3
- Sketch Practice #4

The SolidWorks part files are stored as `.SLDPRT` files and can be opened with
SOLIDWORKS.

## Getting Started

1. Install SOLIDWORKS.
2. Clone or download this repository.
3. Open a `.SLDPRT` file in SOLIDWORKS to inspect or continue the exercise.
