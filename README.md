# CSWA & CSWP Study Projects

This repository contains project files, exercises, and practice models created while studying with **MySolidWorks** and **Coursera** for the **Certified SOLIDWORKS Associate (CSWA)** and **Certified SOLIDWORKS Professional (CSWP)** certification exams.

## Organization

Add files in folders that make them easy to find, such as:

- `cswa/` - CSWA practice parts, assemblies, and drawings
- `cswp/` - CSWP practice parts, assemblies, and drawings
- `coursework/` - Exercises and projects from Coursera courses
- `reference/` - Notes, screenshots, and other study references

## File naming

Use descriptive names that identify the exercise or project, and preserve the native SOLIDWORKS file extensions (`.SLDPRT`, `.SLDASM`, and `.SLDDRW`).
